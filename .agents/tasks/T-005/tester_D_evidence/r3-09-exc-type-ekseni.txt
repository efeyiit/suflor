==============================================================================
  normal dusus                                  -> exc_type=None                 (__exit__ cagrisi: 1)
  return                                        -> exc_type=None                 (__exit__ cagrisi: 1)
  break                                         -> exc_type=None                 (__exit__ cagrisi: 1)
  continue                                      -> exc_type=None                 (__exit__ cagrisi: 1)

  dis finally return ile YUTAR (govde ValueError) -> exc_type=ValueError           (__exit__ cagrisi: 1)

      - generator.throw(RuntimeError)  (RuntimeError)
      - govdede BaseException (KeyboardInterrupt)  (KeyboardInterrupt)
